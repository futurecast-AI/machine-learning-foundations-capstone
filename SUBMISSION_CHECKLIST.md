# ML capstone submission checklist

Author: AI Foundations (Edward Hickman)

## Required contents

- `modeling.ipynb`: executed top to bottom; a supervised regression problem,
  justified preprocessing, trained model, baseline, metrics and three figures;
  final Markdown summary has five sentences with actual performance.
- `module_summary.pdf`: every required report section, actual results,
  in-text citations and APA 7 References with multiple scholarly sources.
- `hour.csv`: original UCI data, 17,379 rows, 17 columns, beside the notebook;
  twelve model inputs, no Titanic or Student Performance reuse.
- `requirements.txt`: generated using actual `pip freeze > requirements.txt`.

## Included extras

Editable DOCX and Markdown report versions; provenance and pre-training plan;
saved predictions, metrics, validation folds, split assignments, figures and
runtime versions; automated checks and report/notebook construction scripts.

## Review before upload

- Read and understand the notebook/report and revise as appropriate.
- Confirm the course permits the disclosed Replit AI assistance.
- Do not describe R² as accuracy, the model as causal, or observed-weather
  evaluation as an operational advance forecast.
- Check whether the course wants the four files, a ZIP, a GitHub link, or both.
- The ZIP contains files, not Git branches or commit history.
- Before merging, a repository link should point to the completed development
  branch/PR, not the initial README on main.
- Instructor and due date were not supplied; neither was invented.
- The supplied APA template's Word styles are retained. PDF export uses
  metrically compatible Liberation Sans instead of Arial.
